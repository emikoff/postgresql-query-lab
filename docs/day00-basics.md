# Day 00. Основы SQL

[← README](../README.md) · [Следующий раздел →](day01-set-operations.md)

Десять запросов знакомят с выборкой, условиями, сортировкой, псевдонимами, вычисляемыми колонками и работой с датами. Решения расположены в [`exercises/day00-basics/`](../exercises/day00-basics/).

Ключевые навыки: `SELECT`, `WHERE`, `BETWEEN`, `IN`, `ORDER BY`, `CASE`, арифметические выражения и фильтрация чётных идентификаторов.

Показательный пример: [`ex08/day00_ex08.sql`](../exercises/day00-basics/ex08/day00_ex08.sql) фильтрует заказы через `MOD` и сортирует результат.
